# Week 1 starter code

The Python files in each day's solutions/ directory are learner starter files, not reference implementations. Their TODO markers are intentional.

For each problem:
1. Read the lesson and problem statement.
2. Implement the function by replacing pass.
3. Run the file with Python to execute its included example assertions.
4. Add your own edge cases before considering the problem complete.
5. Record time and auxiliary-space complexity in your notes.

Do not open an editorial before making a genuine attempt. If you use a hint or reference implementation, record the help level in review.md and later reimplement from a blank file.

The repository does not currently publish separate reference solutions. This keeps the practice path focused on independent implementation rather than copying completed code.
