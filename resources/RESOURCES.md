# Learning resources

This list is a starting point, not a substitute for the lesson sequence. Prefer official documentation for language behaviour and use practice platforms to test your understanding.

## Python foundations

- [The Python Tutorial](https://docs.python.org/3/tutorial/) — official reference for core language features.
- [Python standard library](https://docs.python.org/3/library/) — built-in data structures and modules.
- [Kaggle Learn: Python](https://www.kaggle.com/learn/python) — guided beginner lessons with exercises.

## Data structures and algorithms

- [VisuAlgo](https://visualgo.net/en) — visual explanations of data structures and algorithms.
- [Open Data Structures](https://opendatastructures.org/) — free textbook covering implementations and analysis.
- [MIT OpenCourseWare: Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/) — university-level lectures, notes, and assignments.
- [NeetCode practice](https://neetcode.io/practice) — problems grouped by common interview patterns.
- [LeetCode](https://leetcode.com/) — online judge for submitting and testing solutions.

## Complexity and problem-solving

- [Big-O Cheat Sheet](https://www.bigocheatsheet.com/) — quick reference for common operation complexities. Verify details against the relevant implementation and assumptions.
- [CP-Algorithms](https://cp-algorithms.com/) — detailed algorithm references; some topics are more advanced than this course.

## How to use these resources

1. Start with the session's selected reading; do not open five tutorials at once.
2. Use a visualiser when tracing state changes is difficult.
3. Attempt the problem before reading hints or editorials.
4. Use official Python documentation to resolve language-specific questions.
5. Return to the session quiz and explain the idea in your own words.

Resources may change or become unavailable. If you find a broken link or a better reference, open an issue or submit a focused pull request with the replacement rationale.
